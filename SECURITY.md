# Security Policy / 安全策略

## Reporting a vulnerability / 报告漏洞

This is a personal fork maintained for production use on the owner's own infrastructure.
本仓库是个人 fork，用于维护者自有基础设施上的生产部署。

If you discover a security issue in this fork (or the upstream project it is based on),
please **do not open a public issue**. Contact the maintainer privately:

- GitHub: https://github.com/liuweiqiang0523
- Upstream: report to the original project [gokele/ovh](https://github.com/gokele/ovh) for upstream fixes.

如发现本 fork（或其上游项目）存在安全问题，请**不要公开开 issue**，请私下联系维护者：

- GitHub: https://github.com/liuweiqiang0523
- 上游问题请向原项目 [gokele/ovh](https://github.com/gokele/ovh) 报告，以便上游修复。

## Scope / 范围

- `server/` — Go backend (Gin) / Go 后端
- `web/` — Vite/React frontend / 前端

## Supported / 支持情况

Only the latest release of this fork is supported with security fixes.
本 fork 仅对最新发布版本提供安全修复。
